# FixFlow 前端

Vue 3、Element Plus 与 Vue I18n。真实登录、刷新后的身份核验和退出已连接 Python 后端；问答、资料处理、历史记录和个人资料编辑仍是本机演示。角色由后端返回，不再使用固定演示密码。

## 启动

在 `backend/` 按 [后端说明](../backend/README.md) 启动服务并确认数据库可用，再在 `frontend/` 执行：

```powershell
npm.cmd install # 首次安装前端声明的依赖，已有依赖时无需反复安装。
npm.cmd run dev # 默认监听 5173，并把 /api 请求代理到本机 8100 后端。
```

打开 <http://127.0.0.1:5173/>。本机 Windows 保留了包含 9096 的端口区间，因此默认端口改为 5173。不要为启动项目修改系统端口保留设置；需要临时换端口时可用 `npm.cmd run dev -- --port 5174`。

`VITE_API_BASE_URL` 默认 `/api/v1`；`VITE_BACKEND_TARGET` 默认 `http://127.0.0.1:8100`。前端环境变量会交给浏览器，不能填写数据库密码或其他服务端秘密。开发代理只在开发服务器运行时生效，正式部署需另行配置接口入口。

## 登录账号

网页使用应用账号，与 PostgreSQL 的数据库连接账号不同。没有应用账号时，在 `backend/` 执行以下命令，自行输入并确认至少 12 个字符的密码：

```powershell
.\.venv\Scripts\python.exe -m app.cli create-user --account admin --display-name 管理员 --role admin # 创建网站管理员，密码在终端交互读取，不放入命令参数。
```

`admin` 是示例账号名；如果已经存在，请直接使用已有账号或选择另一个名称。创建普通用户时将 `--role admin` 改为 `--role user`。项目没有默认登录密码；密码不需要发送给开发助手。头像与显示名称编辑仅改变本机演示资料。

## 验证

```powershell
npm.cmd run test:auth # 用 Node 内置测试工具检查认证请求、身份恢复及并发边界，不访问真实数据库。
npm.cmd run check:i18n # 核对中文英文键路径与英文 EN 前缀。
npm.cmd run build # 生成前端生产构建，开发代理不会被打包成正式后端。
```

认证采用已有后端的持有者凭证：本标签页通过临时存储保存凭证和到期时间，刷新后请求身份接口核验；不保存密码或缓存角色。临时存储仍可被页面脚本读取，当前方案不是完整的生产安全部署。网络故障不会冒充账号过期；退出未获后端确认时提供重试，不宣称已撤销凭证。

详细执行流程、选型理由、测试结果与上线差距见本机 [学习文档](../docs/07-前后端真实登录联调与身份恢复-20261019.md)。根目录 `docs/` 按项目规则不随 Git 上传。
